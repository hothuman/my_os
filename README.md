# StudentOS — учебная операционная система

## Назначение

StudentOS — учебный проект, который моделирует основные механизмы операционной системы средствами Python и SQLite. Это не настоящая ОС, которая загружается вместо Windows или Linux, а понятная программная модель ядра, системных вызовов, пользователей, процессов, памяти, файлов, прав доступа, журнала и командной оболочки.

## Требования

- Python 3.10+
- Visual Studio Code
- Git
- Windows 11 (основная среда для сдачи)

Сторонние Python-библиотеки не требуются.

## Запуск

Из корня папки `my_os`:

```bash
python src/db.py
python -m src.shell
```

При первом запуске база `db/os.sqlite` создаётся автоматически.

Учебные учётные записи:

```text
admin / admin123       (роль admin)
student / student123   (роль user)
```

В базе хранятся только SHA-256 хэши паролей. Обычный пользователь не может изменять файлы администратора.

## Структура проекта

```text
my_os/
├── README.md
├── .gitignore
├── docs/
│   └── 01_OS_Scope_and_NFR.md
├── src/
│   ├── __init__.py
│   ├── config.py
│   ├── db.py
│   ├── kernel.py
│   ├── syscalls.py
│   └── shell.py
├── db/
│   └── os.sqlite
├── tests/
└── logs/
```

- `config.py` — настройки и пути проекта.
- `db.py` — подключение к SQLite и создание таблиц.
- `kernel.py` — учебная модель ядра и проверки прав/ресурсов.
- `syscalls.py` — системные вызовы и их журналирование.
- `shell.py` — текстовая командная оболочка.
- `docs/01_OS_Scope_and_NFR.md` — границы системы, сценарии, НФТ, риски и словарь.

## Основные команды оболочки

| Команда | Назначение |
|---|---|
| `help` | Показать справку |
| `echo <текст>` | Вывести текст через системный вызов |
| `users` | Показать пользователей |
| `login <логин> <пароль>` | Войти в систему |
| `whoami` | Показать текущего пользователя |
| `touch <путь> [текст]` | Создать учебный файл |
| `cat <путь>` | Прочитать учебный файл |
| `write <путь> <текст>` | Изменить свой учебный файл |
| `run <имя> [МБ]` | Запустить учебный процесс |
| `ps` | Показать процессы |
| `kill <pid>` | Завершить процесс |
| `mem` | Показать использование памяти |
| `mem <pid> <МБ>` | Выделить память процессу |
| `logs [N]` | Показать журнал вызовов (admin) |
| `clear` | Очистить экран |
| `shutdown` | Завершить StudentOS (admin) |
| `exit` | Выйти из оболочки |
