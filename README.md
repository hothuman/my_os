# StudentOS / StudyOS — учебная операционная система

Учебный проект по УП.02 «Осуществление интеграции программных модулей». Проект имитирует работу операционной системы на Python и SQLite: пользователи, роли, права доступа, файловая система, процессы, память, системные вызовы, журналирование и командная оболочка.

## Возможности

- регистрация и вход пользователей;
- роли `admin`, `user`, `guest`;
- SHA-256 хэширование паролей;
- иерархическая файловая система в SQLite;
- команды `mkdir`, `rmdir`, `touch/create`, `cat`, `write`, `rm/delete`, `rename`, `copy`, `move`, `cd`, `pwd`, `ls`, `tree`;
- управление процессами: `run`, `ps`, `kill`;
- управление памятью: `mem`;
- системные вызовы с логированием статусов `check`, `OK`, `DENIED`, `NOT_FOUND`, `ERROR`;
- 55 автоматических проверок через `tests/run_all.py`.

## Технологии

- Python 3.10+;
- SQLite;
- Markdown;
- Git;
- VS Code.

Внешние Python-пакеты не требуются.

## Запуск

```bash
python src/db.py
python -m src.shell
```

Учётные записи:

```text
admin / admin123     роль admin
student / student123 роль user
user / user1234      роль user
```

## Запуск тестов

```bash
python -m tests.run_all
```

Ожидаемый результат:

```text
Пройдено: 55
Провалено: 0
```

## Основные модули

- `db.py` — SQLite, таблицы, CRUD;
- `kernel.py` — состояние ядра, PID, память;
- `auth.py` — пользователи, хэши, права;
- `logger.py` — журналирование системных вызовов;
- `fs.py` — иерархическая файловая система;
- `scheduler.py` — процессы и планирование;
- `syscalls.py` — системные вызовы;
- `shell.py` — интерактивная оболочка.

## Документация

Ключевые документы находятся в `docs/`: спецификации, матрицы, тест-план, отчёты за дни 4–10, итоговый отчёт, план презентации и защитное слово.
