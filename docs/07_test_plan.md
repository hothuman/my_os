# Тест-план

## Цель
Проверить работу StudentOS: БД, ядро, auth, файловую систему, scheduler, syscalls, shell.

## Область тестирования
Модульное, функциональное, интеграционное, системное, регрессионное и стресс-тестирование.

## Не тестируется
Реальные драйверы, сеть, GUI, многопоточность.

## Критерии начала
Код запускается, база создаётся, основные модули доступны.

## Критерии окончания
`python -m tests.run_all` даёт 0 падений.

## Риски
Ошибки прав, повреждение БД, регрессии после изменения кода.
