# Журнал интеграции

## Сквозной сценарий
1. `login admin admin123` — вход выполнен.
2. `create /report.txt` — файл создан.
3. `cat /report.txt` — содержимое прочитано.
4. `run browser` — процесс создан.
5. `ps` — процесс отображается.
6. `kill PID` — процесс завершён.
7. `mem` — память освобождена.

## Найденные ошибки и исправления

### Ошибка 1: чтение файла возвращало пустую строку
Причина: `sys_read_file` был заглушкой. Исправление: вызов `fs.read_file`.
Статус: исправлено.

### Ошибка 2: удаление не проверяло владельца
Причина: не использовался `fs.get_owner`. Исправление: перед удалением вызывается `check_permission`.
Статус: исправлено.

### Ошибка 3: процесс не освобождал память
Причина: завершение процесса только меняло запись. Исправление: `terminate_process` вызывает `kernel_instance.free_memory`.
Статус: исправлено.
