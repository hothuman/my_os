# Непокрытые функции

Критичные функции покрыты прямыми или интеграционными тестами. Часть функций оболочки проверяется косвенно через импорт и системные вызовы, потому что shell интерактивный.

## Низкий риск
- `print_banner`, `print_files`, `print_logs` — форматирование вывода.
- `clear` в shell — зависит от ОС.
