# Баг-репорты

## BUG-07-01: `sys_read_file` возвращал пустую строку
**Серьёзность:** высокая. **Статус:** закрыт.  
Причина: заглушка. Решение: подключён `fs.read_file`.

## BUG-07-02: user мог удалить чужой файл
**Серьёзность:** высокая. **Статус:** закрыт.  
Причина: не проверялся владелец. Решение: добавлен `get_owner` и `check_permission`.

## BUG-07-03: память не освобождалась после kill
**Серьёзность:** средняя. **Статус:** закрыт.  
Решение: `terminate_process` вызывает `free_memory`.
