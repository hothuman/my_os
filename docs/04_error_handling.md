# Обработка ошибок

| Проверка | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|
| `sys_login('nobody','wrong')` | `False` | `False` | PASS |
| регистрация существующего `admin` | `None` | `None` | PASS |
| пустой пароль | хэшируется и допускается в учебной версии | проходит | PASS |
| удаление чужого файла | `False`, `DENIED` | проходит | PASS |
| завершение чужого процесса | `False`, `DENIED` | проходит | PASS |

В реальной системе пустые пароли следует запрещать политикой безопасности.
