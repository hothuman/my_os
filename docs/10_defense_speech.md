# Защитное слово

Здравствуйте. Я представляю учебный проект StudentOS — модель операционной системы, написанную на Python с использованием SQLite.

Цель проекта — показать, как взаимодействуют основные части ОС: ядро, слой данных, аутентификация, файловая система, планировщик процессов, системные вызовы и командная оболочка.

В проекте есть база SQLite. В ней хранятся пользователи, роли, файлы, процессы, состояние памяти и журнал системных вызовов. Пароли не хранятся открытым текстом: они хэшируются через SHA-256.

Пользователь работает через shell. Команды shell вызывают системные вызовы. Системные вызовы обращаются к модулям fs, scheduler, auth и kernel. Все важные действия записываются в журнал со статусами OK, DENIED, NOT_FOUND или ERROR.

Файловая система учебная и иерархическая. Поддерживаются каталоги, файлы, чтение, запись, удаление, копирование, перемещение и вывод дерева. Процессы можно запускать, смотреть списком и завершать. Память контролируется ядром.

Отдельное внимание уделено проверке прав. Администратор может выполнять все действия, обычный пользователь не может удалять чужие файлы и завершать чужие процессы.

Для проверки написан набор автоматических тестов. Команда `python -m tests.run_all` запускает весь набор и показывает 55 пройденных проверок, 0 проваленных.

В ходе работы были найдены и исправлены ошибки интеграции: чтение файла было заглушкой, удаление не проверяло владельца, память не освобождалась после завершения процесса.

Итог: проект запускается, команды работают, документация и тесты подготовлены. Спасибо за внимание.
